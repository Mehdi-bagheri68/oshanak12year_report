# گزارش راستی‌آزمایی پروژه‌ها و تفکیک مسئولیت‌ها (Project Verification Report)
## ممیزی ۳۶ پروژه مستندشده مهدی باقری در اوشانک (۱۳۹۴ الی ۱۴۰۵)

---

### ۱. چارچوب ممیزی ادعاها و نقش‌ها
برای جلوگیری از هرگونه اغراق، نقش‌های مهدی باقری به شرح زیر تفکیک و اعتبارسنجی شده‌اند:
* **معمار / طراح (Architected / Designed):** مسئولیت مستقیم تدوین ساختار فنی، دیتامدل یا جریان کار (مانند جداسازی OLTP3، فرآیند مودیان، ابزار پاورشل، داشبوردهای BI).
* **رهبر فنی / مدیر استقرار (Led / Deployed):** مدیریت زمان‌بندی، تقسیم کار، هماهنگی تیم‌ها و پاسخگویی به مدیریت ارشد (مانند رول‌اوت اکسپتا، استقرار داینامیکس AX، راه‌اندازی شعب).
* **مجری مستقیم / توسعه‌دهنده (Developed / Implemented):** نگارش اسکریپت‌ها، کانفیگ روترها، کوئری‌های SQL و نصب تجهیزات (مانند اسکریپت POS Dll Replace، Option 150 سیسکو).
* **سرپرست / ناظر (Supervised / Coordinated):** هدایت کارشناسان بومی و تعامل با واحدهای مالی، بازرگانی و PSPها.

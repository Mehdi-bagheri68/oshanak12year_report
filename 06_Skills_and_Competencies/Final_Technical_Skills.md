# مهارت‌ها و شایستگی‌های فنی جامع (Final Technical Skills)
## مهدی باقری بیجاربنه – راهبر فناوری اطلاعات و معمار سیستم‌ها

---

### ۱. معماری و راهبری پایگاه‌های داده (Database Architecture & Administration)
* **پایگاه‌های داده:** Microsoft SQL Server (2012, 2014, 2016, 2019, 2022 Enterprise).
* **بهینه‌سازی کارایی:** Query Store، Execution Plan Analysis، Index Tuning، Columnstore Indexes، Table Partitioning.
* **پایداری و تاب‌آوری:** Always On Availability Groups، Database Mirroring، Disaster Recovery Planning.
* **امنیت داده‌ها:** Role-Based Access Control (RBAC)، Transparent Data Encryption، SQL Server Audit.

### ۲. سیستم‌های سازمانی و فناوری‌های خرده‌فروشی (Enterprise Retail Systems)
* **ERP و صندوق:** Microsoft Dynamics AX 2012/2013 Retail POS، SAP Retail (ZRT96)، Acepta POS.
* **پورتال‌های سازمانی و B2B:** درگاه جامع تامین‌کنندگان (Supplier Portal)، اتوماسیون پروتکل‌های ASN.
* **یکپارچه‌سازی اومنی‌چنل:** اتصال وب‌سرویس‌های فروش آنلاین (اسنپ‌مارکت، مدیسه) به هسته صندوق.

### ۳. اتوماسیون، دواپس و اسکریپت‌نویسی (DevOps & Automation)
* **پاورشل:** ابزار `POS Dll Replace + Config Generate.ps1`، مانیتورینگ خودکار، ساخت کانفیگ‌های XML.
* **اسکریپت‌های سیستمی:** Batch Scripting، T-SQL Scheduled Jobs، ایمیج‌های سیستمی arstemp با Sysprep.
* **تضمین کیفیت:** Atlassian Jira Defect Tracking، تست UAT و آزمون‌های رگرسیون.

### ۴. هوش تجاری و تحلیل پیشرفته داده (Business Intelligence)
* **ابزارهای BI:** Microsoft Power BI، Oracle Business Intelligence (OBI).
* **دیتامادلینگ:** Dimensional Modeling، Star Schema، فرمول‌نویسی پیشرفته DAX، Streaming Datasets.

### ۵. انطباق ملی و فین‌تک
* **سامانه مودیان مالیاتی:** تولید TaxID، امضای دیجیتال نامتقارن PKI، وب‌سرویس‌های TSP، قوانین مالیاتی ماده ۲۲.
* **فناوری پرداخت:** پروتکل‌های شاپرک، مغایرت‌گیری PSPهای سامان‌کیش و پاسارگاد، درگاه‌های اعتباری B2B.
